# Rice Hyprland + SekaiPop

Configuración completa del escritorio basada en **Hyprland (Lua)**, la shell **SekaiPop (Quickshell)**, **Kitty**, **Starship** y **Fastfetch**.

## Características
- Hyprland configurado en Lua con soporte nativo para teclado Latinoamericano (`latam`).
- Atajos adaptados para teclados en español (Super+F1 para cheatsheet, zoom, división de ventanas).
- Quickshell SekaiPop con widgets interactivos, centro de control estilo teléfono y temas dinámicos.
- Terminal Kitty con paleta estética y Starship prompt.
- Detección automática de pantalla para laptops (`eDP-1`) y monitores externos.

## Instalación rápida

En la laptop o PC destino (Arch / CachyOS / EndeavourOS):

```bash
git clone https://github.com/ProgramaGrueso/hyprland-sekaipop-rice.git
cd hyprland-sekaipop-rice
./install.sh
```

El instalador respaldará tus configuraciones anteriores automáticamente antes de aplicar los cambios.
